# ThodTalk v0.3.2 — Улучшения и Фиксы

## ✅ Реализовано

### 1. **Фикс задержки звука при подключении**
   - Увеличены буферы (sync_channel с 8 на 16) для предотвращения underrun-ов
   - Добавлена разминка устройств при инициализации
   - Оптимизирована логика рендеринга звука с буферизацией

### 2. **Auto-reconnect с памятью о последнем сервере**
   - Добавлено `last_server_code` в Profile (сохраняется в storage)
   - Auto-reconnect попытается переподключиться 3 раза с экспоненциальной задержкой (15s, 30s, 60s)
   - Отслеживается когда был último disconnect
   - Память о том, был ли пользователь админом или гостем

### 3. **Per-user muting**
   - Добавлено `muted_users: BTreeSet<Vec<u8>>` в Profile
   - Контекстное меню для каждого пользователя с опциями "Отключить голос" / "Включить голос"
   - Карточка пользователя имеет отдельный тоггл для полного отключения голоса
   - Голос мутанных пользователей не воспроизводится даже если громкость не 0%

### 4. **Расширенные звуковые сигналы**
   - Добавлены новые Sound: MessageMention, UserJoinChannel, UserLeaveChannel, Error
   - Каждое событие имеет уникальный звуковой паттерн для лучшей идентификации

### 5. **FFmpeg Noise Suppression + Voice Enhancement**
   - Добавлены флаги в Profile: `ffmpeg_noise_suppression`, `voice_enhancement`
   - Опции видны в Settings → Звук
   - Готово к интеграции с FFmpeg при обработке микрофонного потока

### 6. **Улучшенный контекстный интерфейс**
   - Right-click меню для каждого пользователя в чате и листе участников
   - Опции: регулировка громкости, мут, админские действия (kick/ban)
   - Карточка пользователя расширена с новыми тогглами

- Добавлены поля: `reconnect_attempts`, `last_disconnect_time`, `last_hosting`
- Auto-reconnect логика в `tick()` функции
- Сохранение `last_server_code` при подключении
- Per-user mute логика в воспроизведении голоса
- Расширенные UI опции в карточке пользователя и контекстном меню

### src/sounds.rs
- Новые Sound типы
- Уникальные звуковые паттерны для каждого события
