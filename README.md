# ThodTalk

Нативное Windows-приложение на Rust для общения с друзьями. В разработке, не готово для повседневного использования.

## Реализовано

- Экран локального профиля: отображаемое имя, выбор и нормализация фотографии, изменение профиля.
- Раздельные настройки согласия на сеть и микрофон. Системные запросы разрешений ещё не интегрированы.
- Защищённые Windows DPAPI файлы профиля, истории и ключей, атомарное сохранение.
- Групповое шифрование OpenMLS, сохранение состояния, проверки удаления участника, повторов, повреждений и посторонних получателей.
- Ограниченное по размерам и очередям TCP-соединение, keepalive, сервер пересылки зашифрованных пакетов с допуском владельцем.
- Интеграционные тесты обмена через TCP и сервер-посредник.

Сетевые модули и история пока не подключены к пользовательскому интерфейсу. Голос, короткие коды, готовый установочный пакет и интеграция выпуска ThodHUB ещё не реализованы. Нельзя выдавать тесты ядра за проверку всего приложения.

## Проверка

На Windows с Rust GNU и MinGW: `./scripts/check.ps1`. Скрипт проверяет код и собирает debug EXE. Зависимости закреплены Cargo.lock.

Данные: THODHUB_DATA_DIR или стандартный каталог %LOCALAPPDATA%/ThodHUB/Data/thodtalk. Для тестирования задавать отдельный THODHUB_DATA_DIR; рабочие данные не удалять.

## Следующие этапы

1. Согласовать внешний узел знакомства/ретрансляции для коротких кодов через интернет.
2. Подключить сервер, проверку идентичностей и историю к интерфейсу; организовать сервер отдельным процессом и корректную остановку.
3. Реализовать голос, устройства, mute/deafen/PTT и E2EE кадров.
4. Проверить два полноценных клиента, упаковку, иконки и зависимость от внешней сети.

Sharkord использован как ориентир функций и структуры интерфейса. Его исходный код и графические ресурсы в этот проект не копировались. Сведения о проверенных исходниках: AUDIT.md. Границы защиты: docs/SECURITY.md.
