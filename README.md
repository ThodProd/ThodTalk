# ThodTalk

Windows-приложение на Rust для голосовых разговоров и текстовых каналов с друзьями.
Клиент и сервер входят в один пакет. Это сборка для совместного тестирования, а не
независимо проверенный продукт безопасности.

## Запуск

Распакуйте ZIP целиком и запустите `app/thodtalk.exe`. Через ThodHUB можно
импортировать тот же ZIP. Устанавливать Rust, Node.js, Python или кодеки не нужно.
Поддерживается Windows 10/11 x64. У приложения пока нет подписи издателя.

1. Укажите имя и выберите фотографию. Сеть и голос разрешены в приложении по умолчанию;
   системные разрешения Windows сохраняют приоритет. Профиль и настройки открываются нажатием на аккаунт внизу слева.
2. Нажмите «Запустить сервер» и затем «Пригласить друзей», чтобы скопировать код.
3. Друзья вводят этот код на главном экране. У всех участников одна версия программы.
4. Для разговора выберите канал и нажмите «Войти» слева под каналами. Рекомендуются наушники.

Если Windows спрашивает доступ через брандмауэр, решение принимает пользователь.
Программа не изменяет правила брандмауэра и настройки безопасности автоматически.
Системные разрешения микрофона Windows имеют приоритет над настройкой приложения.

## Что доступно

- Локальный профиль, смена имени и фотографии; настройки устройств, выбор клавиши (по умолчанию F8) для разговора
  при удержании клавиши в активном окне, выключение микрофона и звука.
- Три общих текстовых и голосовых канала: «Общий», «Игры», «Музыка».
- Один код на запущенную сессию сервера, любое число использований в пределах
  лимита 16 участников. После перезапуска код меняется.
- Кик участника с обновлением ключей и запрет новых подключений.
- Локальная зашифрованная история и её просмотр без подключения.
- Светлая и тёмная темы, системный Segoe UI Variable с запасным Segoe UI.
- Сеть и криптографические операции в отдельном процессе, который завершается
  при отключении и вместе с окном: сначала штатное закрытие QUIC, затем принудительное
  завершение только своего процесса, если он не ответил. Потеря родительского процесса
  также завершает worker. Нет фоновой службы или автозапуска.
- Закрытие окна сворачивает приложение в системный трей. В меню значка есть «Открыть ThodTalk»
  и «Закрыть ThodTalk»; второй пункт завершает приложение и сетевой процесс корректно.

Код TT4 содержит публичный ключ сервера, адрес интернет-relay и случайный секрет входа.
Длина кода переменная; локальные IP-адреса в приглашение не включаются. Его следует копировать целиком, а не набирать вручную.
Код — приглашение для любого получателя. После кика друг может войти снова,
если вход открыт и у него остался код. Бан блокирует текущий ключ локального профиля
до остановки сервера. Создание нового профиля меняет ключ и обходит такой бан:
анонимная система не может надёжно заблокировать человека, а не его ключ.

## Сеть и хранение

При запуске сервер выбирает публичный relay iroh по реальному двустороннему
обмену через интернет. Приглашение появляется только после успешной проверки.
Если ни один маршрут не работает, запуск завершается понятной ошибкой без кода.
LAN-discovery и тестовые переключатели маршрутизации удалены из приложения.
Клиент использует relay из приглашения; через 0,5 секунды параллельно пробует
маршрут без UDP. Первая успешная попытка отменяет остальные. Платных подписок
и аренды нет.
Публичная инфраструктура имеет ограничения нагрузки и доступности: подключение
при любой сети или блокировке провайдера не гарантируется.

Сервер работает только пока компьютер владельца и приложение включены.
Любой друг может создать свой сервер; автоматического переноса работающей
комнаты на другого владельца нет.

Данные находятся в `THODHUB_DATA_DIR`, по умолчанию
`%LOCALAPPDATA%/ThodHUB/Data/thodtalk`. Профиль, история и ключи защищены Windows
DPAPI. Резервная копия привязана к учётной записи Windows; простое копирование
на другой компьютер не гарантирует расшифровку. Переустановка приложения не
удаляет данные. `runtime/` содержит только временную блокировку экземпляра.

Каждый участник сохраняет полученные им сообщения. Старые сообщения не
отправляются автоматически новым участникам. Предел — 10 000 сообщений на
сервер в локальной истории; интерфейс показывает последние 300 сообщений.
Голос не записывается. Личные сообщения, приватные каналы, видеосвязь,
шумоподавление и эхоподавление в этой версии отсутствуют.

## Проверка и сборка

`scripts/check.ps1` запускает тесты и собирает приложение.
`scripts/package-release.ps1` собирает автономный ZIP для GitHub Releases,
описания обновления `thodtalk-release.json` и `thodhub-release.json`, `.sha256`
и `verification.txt` — без зависимости от ThodHUB.
`scripts/release.ps1` проверяет версию и чистоту `main`, запускает тесты,
собирает пакет, ставит тег `hub-vX.Y.Z` и публикует GitHub Release.
`scripts/bump-version.ps1 -Version X.Y.Z` синхронно меняет версию в `Cargo.toml`,
`Cargo.lock` и `hub/manifest.json`.
`scripts/prepare-package.ps1 -HubCheckout <путь-к-ThodHUB>` остаётся для
интеграции с ThodHUB и дополнительной проверки пакета.
Версии зависимостей закреплены в Cargo.lock. Используется Rust GNU и MinGW;
Opus собирается статически. Подробности локальной проверки: `docs/TESTING.md`,
порядок выпуска: `docs/RELEASING.md`.

Ограничения защиты описаны в `SECURITY.md` внутри пакета и `docs/SECURITY.md`
в исходниках. Выпуски: https://github.com/ThodProd/ThodTalk/releases .
Правила для агентов: `AGENTS.md`.

## Обновления

Приложение само проверяет стабильные выпуски `ThodProd/ThodTalk` при запуске и
каждые 6 часов. Новая версия скачивается в фоне, проверяется по размеру,
SHA-256 и manifest. В боковой панели появляется баннер «Доступно обновление»,
а в «Настройки → Обновления» — заметки и кнопка установки. При включённом
автообновлении приложение само перезапускается вне разговора; во время звонка
установка ждёт. Старые файлы сохраняются для отката, профиль и история не
затрагиваются.

## Версия 0.3.12

- Убраны все прикладные лимиты на количество подключений: 16 участников,
  15 пиров relay, 16 входящих QUIC-соединений и 16 голосовых декодеров.
  Теперь число участников ограничивают только ресурсы компьютера и сети.
- Проверка обновлений и установка без изменений; ZIP этого релиза собран с
  прямыми слэшами, поэтому обновление с 0.3.11 проходит штатно.

## Версия 0.3.11

- Исправлено подключение третьего и последующих участников: голосовые
  QUIC-датаграммы могли прийти раньше надёжного Welcome и обрывать сессию
  ошибкой «Нет группы». Ранние голосовые пакеты теперь отбрасываются.
- Код сервера принимается с переносами строк и пробелами: ошибка
  `Invalid symbol 10` при вставке кода из мессенджера больше не возникает.
- Увеличены тайм-ауты публичного relay для мобильного интернета и медленных
  сетей: проверка маршрута ждёт до 30 секунд, вход — до 45 секунд.
- Исправлена упаковка релиза: ZIP для обновления теперь содержит пути с
  прямыми слэшами и проверяется перед публикацией. Старые клиенты больше не
  отклоняют пакет из-за обратных слэшей.

## Версия 0.3.10

## Версия 0.3.0

- Enter отправляет сообщение, Shift+Enter переносит строку. Кнопка «＋» прикрепляет
  изображение до 20 МБ: оно преобразуется в JPEG до 1280 px / 180 КБ без метаданных.
  Изображения передаются внутри MLS и сохраняются отдельно под DPAPI.
- Участники голосового чата находятся слева. Зелёные волны показывают полученный
  звук. Нажатие открывает карточку с громкостью 0–200%; правая кнопка — локальное
  заглушение, а для владельца также кик и бан до остановки сервера.
- F8 — разговор по нажатию, F9 — микрофон, F10 — звук с отключением микрофона.
  Назначения меняются в «Клавиши» и работают в активном окне вне ввода текста.
- Голос использует зашифрованные MLS-пакеты поверх QUIC DATAGRAM, отдельно от
  надёжного потока текста. Старые кадры отбрасываются. Протокол TT3 несовместим
  с TT2: всем друзьям нужна новая версия. Проверка хозяина прекращает сессию
  после 15 секунд отсутствия ответа; мгновенно отличить потерю сети от выхода невозможно.
- Раздел «Обновления» проверяет стабильные hub-v выпуски ThodProd/ThodTalk,
  проверяет размер, SHA-256 и manifest, затем устанавливает пакет с перезапуском
  вне разговора. Старые файлы сохраняются в cache/updates для отката при ошибке.
  В запуске через THODHUB_API обновлением управляет сам хаб. Настройки и история
  не заменяются. Проверка использует только стабильные выпуски официального репозитория.
