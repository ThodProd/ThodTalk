### 3️⃣ Per-user muting (отключение голоса)
- ✅ **BTreeSet<Vec<u8>> мутированных пользователей** (storage.rs:37)

- ✅ **Helper-функция** для сокращения кода: `toggle_user_mute()`
- **Как использовать:** Right-click на пользователя → "Отключить голос"

### 4️⃣ Расширенные звуковые сигналы
- ✅ **4 новых типа звуков** (sounds.rs:13-15):
  - MessageMention (упоминание)

- ✅ **Уникальные звуковые паттерны** для каждого события
- **Результат:** Пользователь может идентифицировать события только по звуку

## 🚀 Как использовать

### Компиляция:
```bash
cd D:\Every\ThodTalk
$env:PATH += ";$env:USERPROFILE\.cargo\bin"
cargo build --release
```

### Запуск:
```bash
target/release/thodtalk.exe
```

### Первый запуск:
1. Создайте профиль с именем
2. Разрешите микрофон и сеть
3. Создайте сервер или присоединитесь к существующему
4. Включите голос (кнопка микрофона)
