# ThodTalk 0.3.4

## Что нового

- **Карточка файла теперь кликабельная.**
  Нажмите на неё — откроется окно с именем, размером и кнопками **«Скачать»** и **«Открыть»**.
  «Скачать» сохраняет файл в выбранное место, «Открыть» запускает его в программе по умолчанию.
  Перед открытием показывается предупреждение о безопасности.
- **Исправлена кнопка скачивания.** Раньше маленькая иконка могла не получать клик; теперь
  работает вся карточка, а в окне файла есть крупная кнопка сохранения.
- **Выбор источника демонстрации экрана.**
  Кнопка «Монитор» больше не запускает трансляцию сразу. Открывается окно, где можно выбрать:
  - весь экран (все мониторы);
  - конкретный монитор (при нескольких мониторах);
  - отдельное открытое окно.
  После выбора нажмите **«Начать трансляцию»** — только тогда демонстрация начнётся.
- **Захват отдельного окна.** Демонстрация показывает выбранное окно, даже если оно перекрыто
  другими окнами. Список окон можно обновить кнопкой «Обновить список».
- **Понятные ошибки.** Если выбранное окно закрылось или Windows не отдал изображение,
  приложение сообщит об этом и остановит трансляцию.

## Важно

- Демонстрация не передаёт звук — только изображение.
- Для демонстрации окна и монитора нужна Windows; на других системах доступен только захват экрана.
- Работать должно с обеих сторон на 0.3.4: старые версии не понимают новые служебные сообщения.
- Перед открытием чужого файла убедитесь, что доверяете отправителю: приложение не проверяет
  содержимое на вирусы.

## Проверки

- 20 юнит-тестов, интеграционный тест воркера и тесты передачи файлов/кадров — успешно.
- Отдельно проверены реальный захват экрана и реального окна через GDI.
