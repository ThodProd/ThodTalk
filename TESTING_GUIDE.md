# ThodTalk v0.3.2 — Инструкция по тестированию

## 🧪 Проверка функционала

### 1. Фиксация задержки звука
**Как проверить:**
1. Запустите два экземпляра приложения на одном компьютере (или двух)
2. Создайте сервер в первом экземпляре
3. Подключитесь со второго экземпляра
4. Включите голос в обоих
5. Говорите и слушайте задержку

**Ожидаемый результат:**
- Задержка между говорением и слышанием должна быть <150ms
- Звук должен быть чистым без artifacts
- Первое подключение к каналу должно быть быстрым

---

### 2. Auto-reconnect функция
**Как проверить:**
1. Создайте сервер (код будет сохранён)
2. Присоединитесь к серверу
3. Закройте приложение сервера
4. Клиент должен автоматически пытаться переподключиться
5. Перезапустите сервер

**Ожидаемый результат:**
- Появится сообщение "Переподключение..." с таймером
- Попытается переподключиться 3 раза (с задержками 15s, 30s, 60s)
- После перезапуска сервера клиент автоматически присоединится

**Примечание:** По умолчанию задержки 15s/30s/60s для быстрого тестирования можно изменить в коде.

---

### 3. Per-user muting
**Как проверить:**
1. Запустите несколько клиентов и подключитесь на одном сервере
2. Включите голос всем
3. Right-click на пользователя в списке справа
4. Нажмите "Отключить голос"

**Ожидаемый результат:**
- Голос этого пользователя больше не будет слышен вам
- Остальные пользователи услышат его голос
- Опция изменится на "Включить голос"
- При перезагрузке приложения настройка сохранится

**Альтернативный способ:**
- Нажмите на карточку пользователя (левее его имени)
- Найдите тоггл "Отключить голос"
- Переключите его

---

### 4. Расширенные звуковые сигналы
**Как проверить:**
1. Включите звуки в Settings → Основное → "Звукозаписи"
2. Присоединитесь к каналу
3. Пригласите другого пользователя (должна быть звуковая сигнализация)
4. Пользователь присоединяется - услышите звук входа
5. Пользователь выходит - услышите звук выхода

**Ожидаемый результат:**
- Каждое событие имеет свой уникальный звук
- Звуки отличаются по высоте и ритму
- Звуки помогают идентифицировать события без смотрения на экран

---

### 5. FFmpeg настройки
**Как проверить:**
1. Откройте Settings → Звук
2. Найдите "Шумоподавление (FFmpeg)" и "Улучшение голоса"
3. Переключите одну из опций
4. Выход из канала и повторное входит
5. Говорите в микрофон и проверьте качество

**Ожидаемый результат:**
- При включении шумоподавления - фоновый шум значительно снижается
- При включении улучшения голоса - голос звучит чище и ярче
- Опции работают независимо одна от другой
- Настройки сохраняются между сеансами

**Тестирование в шумной среде:**
- Включите оба флага
- Говорите в микрофон с шумом (музыка, трафик, кондиционер)
- Слушайте результат с другого клиента

---

### 6. Контекстные меню
**Где искать:**
- Right-click на пользователя в чате
- Right-click на пользователя в списке справа

**Ожидаемый результат:**

- Опции зависят от контекста (администратор ли пользователь, и т.д.)
- Меню закрывается после клика
- Функции меню работают корректно

### 7. Зум и скачивание изображений
**Как проверить:**
1. Отправьте изображение в чат (кнопка "+" внизу)
2. Click на изображение в чате
3. Используйте колесо мыши для зума (вверх/вниз)
4. Right-click на изображении → "Сохранить на компьютер"
5. Проверьте Downloads папку

**Ожидаемый результат:**
- Изображение открывается в полноэкранном режиме с тёмным фоном
- Зум работает плавно и быстро (от 0.5x до 8x)
- Кнопка "×" в правом верхнем углу закрывает просмотр
- Изображение сохраняется с правильным расширением

### 9. Сохранение и загрузка настроек
**Как проверить:**
1. Создайте профиль с корректным именем
2. Измените все настройки (устройства, ключи, громкость)
3. Закройте приложение
4. Откройте заново

- FFmpeg флаги сохранились

## 🐛 Известные проблемы и решения

### Проблема: Высокая задержка звука при первом подключении
**Решение:** Приложение предварительно инициализирует аудио устройство. Первое подключение может быть медленнее, но последующие должны быть быстрыми.

### Проблема: Auto-reconnect не работает
**Решение:** Проверьте что:
1. Опция "Разрешить сеть" включена в Profile
2. Сервер был запущен с "Разрешить сеть"
3. Оба клиента в одной локальной сети

### Проблема: Шумоподавление не работает хорошо
**Решение:** 
1. Проверьте что опция включена в Settings
2. Выход и повторное входит в канал (применяется при следующем подключении)
3. Попробуйте комбинировать с "Улучшением голоса"

### Проблема: Изображения не загружаются
**Решение:** Проверьте размер - максимум 20MB и разрешение 8192x8192.
