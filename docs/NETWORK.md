# Подключение и голос

Сервер комнаты работает на компьютере владельца, пока открыто приложение.
Интернет-соединение использует iroh: прямой QUIC, если сеть позволяет, и relay
для сетей, в которых прямое соединение не устанавливается.

Новые приглашения `TT4:` содержат адреса маршрута, публичный ключ узла и секрет
входа. Поэтому первое подключение не ждёт публикации адреса в DNS/PKARR.
Старые приглашения `TT3:` принимаются, но для новых кодов обеим сторонам нужна
обновлённая сборка. После перезапуска хозяина нужно скопировать новый код.

Перед выдачей кода хозяин проверяет передачу приглашения через relay отдельным
QUIC-клиентом без прямого UDP. Если обмен зависает, пробует следующий регион.
По умолчанию порядок: Азия, запад США, восток США, Европа. Если relay не найден,
интерфейс сообщает об ограничении прямым подключением. При недоступности всех
публичных узлов гарантировать вход через CGNAT невозможно.

Для своего совместимого iroh-relay задайте `THODTALK_RELAY_URLS` перед запуском
приложения. Значение — один URL или несколько URL через запятую, в порядке
предпочтения. Например: `https://relay.example.com`. Некорректный URL вызывает
ошибку запуска, а не скрытое переключение на публичную инфраструктуру.
Поддержка настройки не означает, что отдельный relay уже развёрнут.

Ручной выход и отмена прекращают автоматические попытки. После обрыва гость
повторяет вход на тот же сервер; создание сервера автоматически не запускается.
Общий предел ожидания сетевого процесса — 40 секунд.

Голос передаётся QUIC-датаграммами без повторной передачи старых кадров.
Очереди захвата и кодирования ограничены тремя кадрами по 20 мс; начальный
буфер воспроизведения — 20 мс, накопившийся звук сокращается при превышении
100 мс. Это ограничивает задержку, но не заменяет проверку качества звука
на реальных устройствах и разных интернет-провайдерах.

## Проверки 16 ноября 2026

- Локальные TCP/QUIC, MLS, сообщения, файлы, экран, кик и сохранение истории.
- Три процесса без LAN discovery: сообщения и Opus-кадры в обе стороны,
  проверка ролей хозяина и гостей. Первый замер входа двух гостей — 0,37 с;
  он допускает прямой путь между процессами на одном компьютере.
- Три процесса с `THODTALK_TEST_RELAY_ONLY=1`: вход двух гостей — 5,08 с,
  сообщения, голос в обе стороны и кик прошли. Прямые IP-транспорты отключены.
- Европейский и западноамериканский узлы в этой сети воспроизводили таймаут;
  азиатский маршрут прошёл проверку. Это наблюдение данной сети, а не оценка
  доступности узлов во всех странах.
- Принудительный порядок Европа → Азия: автоматическая смена узла прошла,
  затем два гостя подключились за 4,83 с и обменялись голосом и сообщениями.
- Общий набор: 24 модульных теста и тест отказа worker прошли; три аппаратных
  теста пропущены. Внешние сетевые тесты запускаются отдельно.
- Итоговый `target/release/thodtalk.exe` собран и проверен тем же сценарием
  через `THODTALK_TEST_EXE`: только relay, два гостя вошли за 4,58 с,
  сообщения, голос в обе стороны и кик прошли; весь сценарий занял 12,83 с.

Команды: `scripts/check.ps1`; для внешнего сценария —
`cargo test --locked --test worker_network -- --ignored --nocapture`.
Для обязательного relay установите `THODTALK_TEST_RELAY_ONLY=1`.
Тесты используют временные профили, не записывают микрофон и не проверяют
разговор между двумя физическими компьютерами.
