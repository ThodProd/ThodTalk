# Границы защиты

Приложение находится в разработке. Наличие криптографических тестов не означает аудит безопасности готового продукта.

Ключи и локальные данные защищаются Windows DPAPI от чтения вне профиля Windows. Вредоносное ПО в текущей пользовательской сессии может получить доступ к расшифрованным данным. Перенос зашифрованных файлов на другой компьютер сам по себе не восстанавливает профиль.

Для содержимого групп используется MLS через OpenMLS. Транспортный сервер не должен получать ключи групп. Подлинность первого подключения должна подтверждаться привязкой к ключу владельца или сравнением отпечатков; отображаемое имя не является доказательством личности.

Перед выпуском обязательны интеграция проверки ключей, отзыв участников, безопасное восстановление состояния, тесты нескольких клиентов, проверка границ доступа к истории и полный жизненный цикл голосового соединения.

Сетевые адреса, время и размеры пакетов не скрываются самим MLS. Собеседник может сохранить полученный текст и записать голос.

Решение о внешней инфраструктуре знакомства и ретрансляции принимается отдельно. До его согласования приложение не должно автоматически обращаться к публичным relay.
