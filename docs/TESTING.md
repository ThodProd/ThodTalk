# Сборка 0.3.1

Проверки выполнены 15 ноября 2026 на Windows x64. `cargo test --locked` прошёл:
17 модульных тестов, 1 тест устройств пропущен (открывает устройства на 300 мс),
сетевые публичные сценарии запускаются только явно. Дополнительно проверяются
сборка `cargo build --release --locked`, содержимое пакета, манифест, размер
и SHA-256 через валидатор ThodHUB.

Интерфейс проверен вручную в собранном приложении: главный экран, профиль,
основные настройки, звук, клавиши, обновления, светлая и тёмная темы, чат,
правая панель участников, вход в голосовой канал и карточка аккаунта.
Проверка обновлений в release-сборке возвращает «Установлена последняя
опубликованная версия» без ошибки процесса обновления. Ниже сохранён
исторический отчёт 0.2.1.

# Отчёт проверки сборки 0.2.1

Проверки выполнены 13 ноября 2026 на Windows x64. Все автоматические сценарии
используют отдельные временные профили; рабочие пользовательские данные не менялись.

## Проверено

- Групповое MLS-шифрование, отклонение повреждений, повторов и постороннего
  получателя; удалённый участник не расшифровывает новую эпоху.
- Реальные TCP/QUIC-соединения, проверка секрета приглашения и закрытого входа.
- Три локальных клиента: текст, Opus-аудиокадр внутри MLS, кик, сохранение истории,
  неизменность общего кода и новый код при перезапуске.
- Публичный маршрут iroh с отключённым LAN discovery: библиотечный тест трёх
  клиентов прошёл за 91,26 с; тест трёх отдельных процессов готового EXE — за
  81,38 с. Проверены текст, зашифрованный аудиокадр, кик и работа оставшихся
  участников при закрытом входе. Это три процесса на одном компьютере,
  а не три разных провайдера. Потребовались повторные подключения.
- Профиль и история DPAPI, атомарное сохранение, ошибки повреждения файлов.
- Worker отклоняет неправильное приглашение и завершается после закрытия stdin.
- Устройства микрофона и вывода на этом компьютере открылись без ошибок;
  тест длился 300 мс, передача была выключена, запись не создавалась.
- В окне вручную проверены запуск сервера, отправка сообщения клавиатурой и
  завершение процесса при закрытии окна. Новый тёмный дизайн визуально проверен.
- EXE использует только системные DLL Windows; Opus и Rust runtime включены.

Окончательный результат сборки и упаковки фиксируется в
`dist/0.2.1/verification.txt`. Файл не содержит приглашений, профилей или ключей.

## Проверить вместе с друзьями

1. На двух-трёх компьютерах в разных сетях войти по одному коду. Затем назначить
   другого друга хостом и повторить. При необходимости обработать штатный запрос
   брандмауэра вручную; на первом подключении дождаться повторных попыток.
2. В наушниках поговорить 10–15 минут: микрофон, «Без звука», F8, переключение
   каналов и устройств. Оценить задержку, прерывания и нагрузку. Акустическое
   качество на нескольких физических устройствах автоматически не проверялось.
3. Изменить имя/фото, перезапустить приложение и проверить историю. Кикнуть
   участника, закрыть вход и убедиться, что остальные продолжают общение.

## Воспроизводимость

`scripts/check.ps1` — обычные тесты и сборка. Дополнительные сетевые проверки:

```
cargo test --release --test internet -- --ignored --nocapture
cargo test --release --test worker_network -- --ignored --nocapture
```

Для теста `internet` переменная `THODTALK_TEST_PUBLIC_ONLY=1` отключает LAN
discovery; тест worker_network устанавливает её в дочерних процессах сам.
Диагностический `THODTALK_TEST_TRACE` задаёт путь журнала сетевого теста.
Такой журнал может содержать сетевые адреса; в пакет он не включается.

Непроверенные условия: разные провайдеры и CGNAT, длительные многолюдные
разговоры, Bluetooth-гарнитуры всех моделей, приостановка Windows и смена сети
во время разговора. Светлая тема и минимальный размер окна ещё требуют
пользовательской оценки. Эти сценарии не выдаются за прошедшие тесты.
